What I built

งานนี้บิ๊กสร้างเว็บไซต์ Learning Portfolio แบบหน้าเดียว เพื่อที่จะแนะนำตัวเองให้กับอาจารย์ให้ได้รู้จักถึงตัวตนของผมและนำเสนอสิ่งที่อาจารย์ได้สอนมา

How I built it

ผมสร้างโดยใช้ HTML และนำความรู้จากที่อาจารย์สอนในคาบ และใช้สื่อการเรียนรู้เช่น youtube กับ google เพื่อมาพัฒนาเว็บไซต์นี้ และใช้ css เพือตกแต่งนิดเช่น ตำแหน่งข้อความ เพื่อให้ดูมีความน่าสนใจมากขึ้น ถึงจะไม่ขนาดนั้นก็ตาม

Reflection

จากปัญหาที่ได้พบ ผมไม่ค่อยเก่งเรื่องการ coding และไม่ค่อยมีจินตนาการในการตกแต่งเว็บไซต์เพื่อให้มีความน่าสนใจมาก แต่ผมก็พยายามหาข้อมูลจากแหล่งต่างๆ และสไลด์ที่อาจารย์ได้แนบไว้ จากการพัฒนาเว็บ A1 นี้ ผมเข้าใจมากขึ้นว่า มาทำวันสุดท้ายไม่ช่สิ่งที่ควรทำเลย555+ เราควรจัดสรรเวลาเพื่อทำงาน ไม่ใช่เอาแต่สนุก เที่ยวหรือทำอย่างอื่นอย่างเดียว หากผมได้พัฒนาเว็บไซต์นี้/งานนี้ต่อ ผมอยากตกแต่งให้สวยงามมากขึ้น เพราะว่างานนี้ทำแบบไฟลนก้นมาก
